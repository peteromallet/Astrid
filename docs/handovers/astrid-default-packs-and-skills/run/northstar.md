# Direction

Astrid has one clear skill entry point. Setup installs the default Hivemind pack
from its canonical pinned source; installed pack-owned skills are linked beneath
that entry point. Creative work routes to the pack that owns execution, including
combined timeline editing/rendering. Pack builder explains how to extend it.

Skills and runtime consume the same enabled sources. Preserve all seven Hivemind
executors, source verification, user opt-outs and unrelated work. Avoid copied
executors, personal-path dependencies, network activity during skill sync and
speculative installer frameworks.

Adopted from the approved implementation plan and the user's architectural steering.
