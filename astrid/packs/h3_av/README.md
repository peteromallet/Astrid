# H3 audiovisual transformations

This pack turns one small request into a deterministic preparation manifest,
an H3 workflow bundle, a generated candidate, and preservation evidence. The
public request uses `changes.video` and `changes.audio` schedules. The active
H3 pack contract supports source-backed edits, native continuation, references,
and explicit mask assets without creating a second project or task database.

`operation: generate` is not admitted by this pack. The packaged H3 resources
contain starter-oriented nodes, but the settled Astrid route is bound to the
source-backed continuation graph and does not expose a verified source-free
output path. Requests with no source and no masks therefore fail before
preparation/runtime admission; this README does not claim source-free support.

The current compiler targets the repaired Seitanism MiniMax H3 AV graph at
`workflows/seitanism_h3_av_extension_repaired/`. It fails closed when a request
asks for a graph feature that the selected workflow cannot represent. Runtime
admission and RunPod lifecycle remain Astrid/VibeComfy responsibilities.
